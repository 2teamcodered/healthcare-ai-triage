# Healthcare AI Triage Prototype

A deliberately conservative prototype for demonstrating structured symptom intake and escalation logic. It does **not** diagnose, prescribe, or replace a clinician.

## Safety
This project is educational only. In a real deployment, use clinical validation, privacy controls, bias testing, human oversight, and applicable regulations. For urgent symptoms, contact local emergency services.

```bash
python -m triage.demo
```
